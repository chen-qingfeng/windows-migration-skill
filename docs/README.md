## 一句话结论

> **"一键全量搬家"作为消费级产品走不通**——低频、免费竞品、无入口、责任无法承担。
> **但"换电脑时把机器清点清楚"这件事没人做好**，而且它零风险、零门槛、可传播。
>
> 所以这个项目**只做体检，不做搬运**。v0.1 物理上不可能弄坏你的电脑。

## 关于这些文档

- 它们是作者的工作笔记，保留了大量"否定自己"的推演过程，没有做成对外宣传稿。
- 里面的评分、阈值、时间线都是**可证伪的假设**，不是结论。
- 竞品数据截至 2026-11，星数来自 GitHub API 实测。

如果其中某一条判断后来被证明是错的，欢迎开 issue 打脸——那正是这个项目想收集的东西。
